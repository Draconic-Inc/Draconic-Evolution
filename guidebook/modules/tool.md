# Tool Modules

## <ItemImage id="draconicevolution:item_draconium_damage" scale = "0.5"/> <ItemLink id="draconicevolution:item_draconium_damage"/>
*Supported in all tools.*

Damage modules increase the damage dealt by the item.

## <ItemImage id="draconicevolution:item_wyvern_aoe" scale = "0.5"/> AOE Module
*Supported in all tools.*

AOE modules increase the working area of the tool. (adjustable)

## <ItemImage id="draconicevolution:item_wyvern_ender_collection" scale = "0.5"/> <ItemLink id="draconicevolution:item_wyvern_ender_collection"/>
*Supported in all tools.*

When a Ender Collection module is installed, items dropped by the tool will be transferred to your Ender Chest. If Ender Storage is installed, **<KeyBind id="key.sneak"/> + <KeyBind id="key.use"/>** an Ender Chest to link the module to that frequency. (adjustable)

## <ItemImage id="draconicevolution:item_wyvern_junk_filter" scale = "0.5"/> <ItemLink id="draconicevolution:item_wyvern_junk_filter"/>
*Supported in all tools.*

Selective Incineration modules can be configured with up to nine items and/or tags. Items dropped by the tool that match the filter will be voided. (adjustable)

## <ItemImage id="draconicevolution:item_wyvern_tree_harvest" scale = "0.5"/> Tree Harvest Module
*Supported in axes and staffs.*

When a Tree Harvest module is installed, hold **<KeyBind id="key.use"/>** to chop the tree you're looking at. (adjustable)
