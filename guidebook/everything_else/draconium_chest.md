# Draconium Chest

The Draconium chest is probably one of the most versatile storage devices around! Not only does it have 260 inventory slots, but it also has a powerful multi-slot furnace, and a crafting table for your convenience! The chest stores its inventory when broken, And you can make it any color you want.

## The Furnace

The built-in furnace is no ordinary <ItemLink id="minecraft:furnace" />. It can smelt 5 items at a time at a very reasonable speed. However, the furnace requires power; which can either be supplied externally, or with a [Flux Capacitor](../equipment/modular_tools.md) in its capacitor slot.

The furnace also has an auto-feed option, which automatically feeds the furnace smeltable items from the inventory. There are four feed modes:

- **OFF**: Disables auto-smelting.
- **FILL**: Only feeds the furnace when there are already items smelting and will only keep the existing stacks currently smelting full. Will *not* start to smelt items types that you have not manually placed in the furnace.
- **LOCK**: Similar to **FILL**, except it will not smelt the last item; meaning as soon as more of that item shows up in the inventory, it will automatically start feeding again.
- **ALL**: Smelts every smeltable item in the inventory.

The furnace also has four redstone modes:
- **Always Active**
- **With Redstone Signal**
- ***Without* Redstone Signal**
- **Never Active**

## Crafting Table

Acts like a normal <ItemLink id="minecraft:crafting_table" />, except it retains items inside its slots.
