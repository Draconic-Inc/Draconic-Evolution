# Celestial Manipulator

The Celestial Manipulator can change the time and weather (if you can supply enough OP to it).

This device has two main operating modes, Time and Weather. Each mode has different functions:

Weather:
- Stop Rain
- Start Rain
- Start Thunderstorm

Time:
- Skip to sunrise
- Skip to mid-day
- Skip to sunset
- Skip to moonrise
- Skip to midnight
- Skip to moonset
- Skip 24 Hours
  - This function skips to the same time the next Minecraft day. Combined with the stop button, you can effectively set the time to whatever you want.

This device can also be configured for redstone control. In the redstone control tab, you can select which time or weather function to execute when given a redstone signal. If set to `Skip 24`, the time acceleration will stop early if the redstone signal stops. 


> Note: Changing the time does not actually speed up game ticks, it just changes the world time.
